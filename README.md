# JJ-stash-config
## Stash iOS Config File

### 🔗 Step 1. 导入配置文件

#### 在Stash首页左上角，点击进入配置列表,导入-从URL下载，填写以下链接或扫描二维码。
**Original link:**
```text
https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```
<img width="150" height="150" alt="JJ-stash-config-url-qr" src="https://github.com/user-attachments/assets/1df56333-cff2-42f2-ae40-9f7421c51a9f" />

**China acceleration 🚀:**
```text
https://cdn.jsdelivr.net/gh/sydneygao/JJ-stash-config@main/JJ-config.yaml
```

#### 直接使用相机📷扫描二维码，快速导入Stash:
**Original link:**
```text
stash://install-config?url=https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```

**China acceleration 🚀:**
```text
stash://install-config?url=https://cdn.jsdelivr.net/gh/sydneygao/JJ-stash-config@main/JJ-config.yaml
```

### ✈️ Step 2. 填写机场订阅
在Stash首页左上角，点击进入配置列表, 找到已导入的 `JJ-config.yaml`，编辑（可视化编辑器）-远程代理集，添加机场订阅。
