# JJ-stash-config
## Stash iOS Config File

### 🔗 Step 1. 导入配置文件

#### 在 Stash 首页左上角进入配置列表，选择“导入 → 从 URL 下载”，填写以下任一链接或扫描对应二维码。

**主链路（gh-proxy.org｜最快，≤60 秒更新）：**
```text
https://gh-proxy.org/https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```

**备链路（gh.idayer.com｜不同链路，实时）：**
```text
https://gh.idayer.com/https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```

<p align="left"><img width="180" alt="JJ-config.yaml URL 主链接二维码" src="./assets/qr/JJ-config-url-primary-mirrors.svg" /> <img width="180" alt="JJ-config.yaml URL 备用链接二维码" src="./assets/qr/JJ-config-url-backup-mirrors.svg" /></p>

**兜底链路（cdn.jsdelivr.net｜最稳，接受最长约 12 小时延迟）：**
```text
https://cdn.jsdelivr.net/gh/sydneygao/JJ-stash-config@main/JJ-config.yaml
```

#### 直接使用相机📷扫描二维码，快速导入 Stash：

**主链路（gh-proxy.org｜最快，≤60 秒更新）：**
```text
stash://install-config?url=https://gh-proxy.org/https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```

**备链路（gh.idayer.com｜不同链路，实时）：**
```text
stash://install-config?url=https://gh.idayer.com/https://raw.githubusercontent.com/sydneygao/JJ-stash-config/main/JJ-config.yaml
```

### ✈️ Step 2. 填写机场订阅
在 Stash 首页左上角进入配置列表，找到已导入的 `JJ-config.yaml`，选择“编辑（可视化编辑器）→ 远程代理集”，添加机场订阅。
